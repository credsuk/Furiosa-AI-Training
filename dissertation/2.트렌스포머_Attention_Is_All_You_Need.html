PART 1 · SEQ2SEQ의 한계
Seq2Seq의 동작과 고정 컨텍스트 병목
단어가 들어올 때마다 히든 스테이트를 갱신 → 이전 단어들의 정보가 누적된다.
마지막 단어에서의 히든 스테이트 = 소스 문장 전체를 대표하는 컨텍스트 벡터.
디코더는 컨텍스트에서 출발해 이전 출력을 다시 입력으로 받으며 EOS가 나올 때까지 반복.
문장이 짧든 길든 고정된 크기 하나에 소스 문장 전체를 압축 → 병목 → 성능 하락.
또 단어를 순서대로만 처리해서 병렬화가 어렵다.
컨텍스트를 매 디코더 셀에 넣어 정보 손실을 줄인다 — 그래도 하나의 벡터에 압축해야 하는 건 그대로.

인코더의 셀프 어텐션: 각 단어가 서로에게 어텐션 스코어를 구해 → 입력 문장의 문맥을 학습한다.
어텐션 → 잔차 연결 + 정규화 → 피드 포워드 → 잔차 연결 + 정규화 = 인코더 레이어 하나.
레지듀얼 연결 — 레이어를 건너뛴 입력을 그대로 더한다. 남은(residual) 부분만 학습하니 학습이 쉬워지고 수렴이 빠르다 (ResNet의 아이디어).
레이어를 N번 중첩. 레이어마다 파라미터는 서로 다르고, 입력과 출력의 차원은 같다.

PART 3 · SCALED DOT-PRODUCT ATTENTION
어텐션을 수식으로
Attention(Q, K, V) = softmax( QKT / √dk ) V
QKT — 각 쿼리와 각 키를 곱해서 에너지(연관도 점수)를 구한다.
√dk로 나누는 이유 — dk는 키의 차원. 값이 커지면 소프트맥스가 양 끝으로 쏠려 기울기가 거의 0이 된다(기울기 소실). 나눠서 값을 줄이면 학습이 잘 된다.
softmax(…) · V — 소프트맥스로 얻은 확률(가중치)을 밸류에 곱해 더하면 어텐션 값.
헤드마다 서로 다른 리니어 가중치 Wi → h개의 서로 다른 Q·K·V → 서로 다른 어텐션 컨셉을 학습.
headi = Attention(QWiQ, KWiK, VWiV)
MultiHead(Q, K, V) = Concat(head1, …, headh)·WO
입력과 출력 차원이 같아서 레이어를 중첩할 수 있다. 시각화하면 헤드 수(h)만큼 어텐션 그림이 나온다.

PE(pos, 2i)   = sin( pos / 100002i/dmodel )
