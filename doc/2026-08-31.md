## 이날의 주제: Python 기본과 Keras 선형 회귀

Python 변수·연산·출력에서 시작해 TensorFlow/Keras의 Sequential, Dense, MSE, Adam, fit/evaluate/predict 흐름을 익혔습니다. 작은 데이터로 입력과 출력의 관계를 확인하는 단계입니다.

## 반드시 기억할 내용

입력 X와 정답 y를 분리하고, 모델을 구성한 뒤 compile → fit → evaluate/predict 순서를 지킵니다. Dense의 input_dim은 샘플 수가 아니라 한 샘플의 특성 수입니다.

```text
데이터(X, y) → 모델(Sequential/Dense) → compile → fit → evaluate/predict
```

## 학습 보강: Python·NumPy·pandas

### Python 문법 반복

`X`와 `y`는 값을 담는 변수입니다. `model.fit(X, y)`에서 함수에 값을 전달할 때는 **변수 자체가 아니라 변수가 가리키는 데이터**가 전달됩니다. `model = Sequential()`처럼 함수 호출 결과를 다시 변수에 저장하는 것도 같은 원리입니다.

```python
x = [1, 2, 3]
y = [value * 2 for value in x]
```

대괄호의 리스트 컴프리헨션은 `x`의 값을 하나씩 꺼내 `value * 2`를 계산해 새 리스트를 만듭니다. 다음 단계에서는 이 문법을 NumPy 배열 연산과 비교해 봅니다.

### NumPy 핵심

`np.array()`는 Python 리스트를 배열로 바꾸고, `.shape`는 각 축의 길이를 튜플로 반환합니다. `reshape()`는 원소 수를 유지한 채 모양만 바꾸므로 원소 수가 맞지 않으면 오류가 납니다.

```python
x = np.array([[1], [2], [3]])
print(x.shape)          # (3, 1)
print(x.reshape(1, 3).shape)  # (1, 3)
```

이날 학습 기록에서 pandas의 직접 사용은 확인되지 않았습니다. CSV 학습으로 넘어가면 `pd.read_csv()`의 반환값이 DataFrame이라는 점부터 반복합니다.

### 반복해서 기억할 점

`input_dim`은 데이터 전체 행 수가 아니라 **한 샘플의 feature 수**입니다. 모델에 넣기 전 `X.shape`, `y.shape`를 먼저 출력하는 습관을 유지합니다.
