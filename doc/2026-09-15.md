
## 학습 보강: 이미지 배열과 추론 전처리

### Python 문법 반복

`for` 반복문으로 여러 파일을 처리할 때 현재 파일 경로와 결과 배열을 구분하는 변수를 사용합니다. 함수가 만든 배열을 `return`하고 호출부에서 받는 흐름을 다시 연습합니다.

### NumPy 핵심

`img_to_array(image)`는 이미지를 NumPy 배열로 변환합니다. `astype()`은 자료형을 바꾸고 `/ 255.0`은 픽셀 값을 스케일링합니다. `np.expand_dims(x, axis=0)`은 한 장을 batch 1장으로 만듭니다.

```python
x = img_to_array(image).astype('float32') / 255.0
x = np.expand_dims(x, axis=0)
```

### pandas 확인

이미지 파일과 라벨 목록을 CSV로 관리했다면 pandas의 행 순서가 이미지 배열 순서와 일치하는지 확인해야 합니다. 이 날짜의 핵심 코드는 이미지·NumPy·Keras이며 pandas 직접 사용은 확인되지 않았습니다.

### 반복해서 기억할 점

학습과 추론의 resize, channel 순서, 스케일, label encoding이 하나라도 다르면 예측 결과를 신뢰할 수 없습니다.
