## 이날의 주제: 이미지 데이터셋 저장·복원 실습

horse·RPS·men/women 데이터의 NPY 저장·복원, 이미지 배열 변환, 모델 저장 결과를 연결했습니다.

## 반드시 기억할 내용

파일을 저장하는 것과 모델을 저장하는 것은 별개의 계약입니다. 데이터 shape와 모델 입력 shape를 각각 확인해야 합니다.

```text
원본 이미지 → NPY 데이터셋 → train/test → CNN
모델 → model/weights 파일 → load → 새 이미지 추론
```

## 학습 보강: 데이터셋 저장과 모델 저장 구분

### Python 문법 반복

저장·복원 코드는 `save()`와 `load()`의 인자 경로가 계약입니다. 같은 이름의 변수를 재사용하면 원본 이미지, 배열 데이터셋, 모델 객체가 섞일 수 있으니 단계별 변수명을 구분합니다.

### NumPy 핵심

`np.save()`는 단일 배열, `np.savez()`는 여러 배열을 저장할 수 있습니다. `np.load()` 뒤에 `.shape`, `.dtype`를 확인하고, 이미지 batch라면 `(n, h, w, c)`를 모델 input shape와 비교합니다.

### pandas 확인

파일명·라벨·경로를 DataFrame으로 관리하는 경우 `df[['path', 'label']]`은 DataFrame, `df['label']`은 Series라는 차이를 기억합니다. 배열로 변환하기 전 열 순서를 고정합니다.

### 반복해서 기억할 점

데이터 파일을 저장한 것과 모델 구조·가중치를 저장한 것은 별개입니다. 복원 후 첫 샘플 shape와 예측 출력 shape를 바로 확인합니다.
