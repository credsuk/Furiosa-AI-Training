## 중요한 내용 — 초보자용 설명

### 1. RAG는 책에서 관련 페이지를 찾아 답하는 방식입니다

`RAG/rag19_PyPDF_2_챗봇.py`와 `RAG/reg20_embedding4_챗봇.py`의 흐름은 다음과 같습니다.

1. `PyPDFLoader`가 PDF를 페이지별 문서 목록으로 읽습니다.
2. `load_and_split()`과 text splitter로 긴 문서를 작은 조각으로 나눕니다.
3. 임베딩 모델이 문장 조각을 숫자 목록(벡터)으로 바꿉니다.
4. `FAISS.from_documents()`로 벡터 검색 저장소를 만들고 저장합니다.
5. `FAISS.load_local()`로 저장된 저장소를 다시 읽습니다.
6. `as_retriever(search_kwargs={"k": 3})` 또는 `k=2`로 질문과 가까운 조각을 검색합니다.
7. 검색된 조각은 prompt의 `{context}`에 들어가고, 질문은 `{input}`에 들어갑니다.
8. retrieval chain이 답을 만들고 `response['answer']`를 Gradio `ChatInterface`에 반환합니다.

`allow_dangerous_deserialization=True`는 pickle 계열 데이터를 읽는 위험한 역직렬화를 허용하는 옵션입니다. 파일 출처를 믿을 수 있을 때만 사용해야 하며, 이 옵션 자체가 파일을 안전하게 만들어 주는 것은 아닙니다.

`reg20_embedding2_bge-m3.py`는 `BAAI/bge-m3`를, `reg20_embedding3_qwen3.py`는 `Qwen/Qwen3-Embedding-0.6B`를 사용합니다. 코드 주석에는 벡터 차원이 적혀 있지만, 현재 실행 결과로 다시 확인한 값은 아닙니다.

### 2. 다중 입력 앙상블은 여러 표를 같은 사람의 기록처럼 맞춰 합치는 것입니다

`keras69_ensemble1.py`은 `(100, 2)` 입력과 `(100, 3)` 입력을 각각 다른 Dense 층에 통과시킨 뒤 합칩니다.

- 첫 번째 `100`: 샘플이 100개라는 뜻입니다.
- 두 번째 숫자 `2` 또는 `3`: 샘플 하나가 가진 feature 개수입니다.
- 첫 번째 가지의 출력은 `(batch, 80)`입니다.
- 두 번째 가지의 출력은 `(batch, 40)`입니다.
- `Concatenate` 후에는 `(batch, 120)`이 됩니다.
- 마지막 `Dense(1)`은 샘플마다 예측값 하나를 만듭니다.

`keras69_ensemble2.py`은 `(100, 4)`인 세 번째 입력 가지를 추가합니다. `train_test_split`에 모든 입력과 정답을 함께 넣는 이유는 같은 샘플들이 같은 train/test 분할로 함께 움직이게 하기 위해서입니다. 샘플 순서가 어긋나면 서로 관계없는 입력과 정답을 연결하게 됩니다.

### 3. 다중 출력은 한 모델이 두 가지 답을 따로 내는 것입니다

`keras69_ensemble3.py`은 세 입력 가지를 합친 뒤 `last_output1`과 `last_output2` 두 출력을 만듭니다. 모델 정의의 출력 순서가 `outputs=[last_output1, last_output2]`이므로 학습 정답도 `[y1_train, y2_train]` 순서여야 합니다. 평가 때도 `[y1_test, y2_test]` 순서를 유지해야 합니다.

`last_dense1`, `last_dense2`는 층을 만들었지만 `last_output1`이 `merge3`에서 바로 시작하므로 실제 출력 경로에 연결되지 않습니다. 코드에 이름이 있다는 것과 계산 그래프에 연결되어 있다는 것은 다릅니다.

### 4. 코드 주석의 숫자와 실제 검증 결과를 구분합니다

세 Keras 파일 끝의 loss와 predict 숫자는 주석으로 기록된 예시입니다. 이번 복습에서는 TensorFlow 학습을 다시 실행하지 않았으므로 현재 환경에서 그 숫자가 재현된다고 말할 수 없습니다. RAG도 PDF, 로컬 임베딩 모델, FAISS 저장소, API 자격증명, Gradio가 준비되어 있는지와 실제 서버 실행을 확인하지 않았습니다.

## 반드시 기억할 점

1. RAG 순서는 문서 읽기 → 청킹 → 임베딩 → 벡터 저장/검색 → context와 질문을 prompt에 넣기 → LLM 답변입니다.
2. `np.array([range(100), range(301, 401)]).T`의 shape는 `(100, 2)`입니다.
3. `(batch, 80)`과 `(batch, 40)`을 마지막 축으로 이어 붙이면 `(batch, 120)`입니다.
4. 다중 입력은 첫 번째 축의 샘플이 서로 같은 대상을 가리켜야 합니다.
5. 다중 출력의 출력 목록과 정답 목록은 같은 순서여야 합니다.
6. `allow_dangerous_deserialization=True`는 신뢰 가능한 저장 파일에만 제한적으로 사용합니다.
7. 연결하지 않은 Keras 층은 모델 출력 계산에 참여하지 않습니다.
8. `axis=1`은 pandas에서 열 방향을 뜻합니다.
9. 코드의 주석 숫자는 실행 기록일 수 있지만, 이번 실행에서 재현한 결과와는 구분해야 합니다.

                         ├→ last_output1 → y1
                         └→ last_output2 → y2

## Python·NumPy·pandas 연결

- Python: `answer_invoke(message, history)`는 입력을 받아 `response['answer']`를 반환합니다. 실제 반환 키가 있는지는 실행 환경과 chain 결과 확인이 필요합니다.
- NumPy: `.T`와 `.transpose()`는 축 순서를 바꿉니다. 두 개의 길이 100인 1차원 자료를 쌓고 전치하면 샘플 100개, feature 2개가 됩니다.
- pandas: `df.drop([target], axis=1)`에서 `axis=1`은 열을 제거한다는 뜻입니다. 당일 코드에는 pandas 실행이 없으므로 DataFrame 결과는 실행 사실로 주장하지 않습니다.
