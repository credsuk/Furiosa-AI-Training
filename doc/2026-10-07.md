## 초보자용 설명

오늘 복습은 새 코드가 추가된 날의 학습이 아니라, 최신 학습 코드에 나온 데이터 준비와 shape를 다른 형태로 다시 확인하는 날입니다. Python 함수는 내부 계산값을 반환해야 바깥에서 사용할 수 있고, NumPy의 `reshape`는 원소 수를 바꾸지 않은 채 축을 재배치합니다. pandas에서 열을 제거할 때는 `axis=1`을 사용하며, scaler는 train의 기준을 test에 그대로 적용해야 test 정보가 학습 기준에 섞이지 않습니다. 문장 데이터는 길이가 제각각이므로 padding 후 고정 길이 sequence로 만들고, LSTM은 `(batch, timestep, feature)` 순서의 입력을 받습니다.

## 핵심 기억

1. Python 지역변수는 함수가 끝난 뒤 직접 접근할 수 없고, 필요한 값은 `return`으로 전달해야 합니다.
2. `np.arange(24).reshape(2, 3, 4)[:, :, 1]`의 정적 shape는 `(2, 3)`입니다.
3. `axis=1`은 DataFrame의 열 축이며, `fit_transform`은 train, `transform`은 test에 적용합니다.
4. token index의 최댓값이 1999라면 `input_dim`은 최소 2000이어야 합니다. 실제 reserved index와 전처리 규칙도 함께 확인해야 합니다.
5. `(8708, 8)`을 `(?, 4, 2)`로 reshape하면 batch는 8708, timestep은 4, feature는 2입니다. 원소 수 보존 여부도 확인해야 합니다.
6. `Dense(10)` 예측은 보통 `(10000, 10)`, `argmax(axis=1)` 결과는 `(10000,)`입니다.
