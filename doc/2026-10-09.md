## 중요한 내용 — 초보자용 설명

### 1. RAG는 책에서 답을 찾아 알려주는 흐름입니다

RAG는 AI가 모든 답을 머릿속에서만 만들지 않고, 먼저 문서에서 관련 부분을 찾은 뒤 그 내용을 참고해 답하는 방식입니다.

1. `PyPDFLoader`가 PDF를 페이지 문서 목록으로 읽습니다.
2. 문서를 작은 조각으로 나누는 청킹을 합니다.
3. 임베딩 모델이 문장을 숫자 벡터로 바꿉니다. 숫자 벡터는 문장의 의미를 비교하기 위한 주소표처럼 생각할 수 있습니다.
4. FAISS가 벡터를 저장하고 질문 벡터와 가까운 조각을 찾습니다.
5. 검색된 조각을 prompt의 `{context}`에 넣고 LLM에 전달합니다.
6. Gradio의 `ChatInterface`가 질문과 답변을 화면에 연결합니다.

코드에는 `k=2` 또는 `k=3`이 있습니다. 이것은 질문과 가까운 문서 조각을 몇 개 가져올지 정하는 값입니다. `FAISS.load_local(..., allow_dangerous_deserialization=True)`는 저장된 pickle 데이터를 읽을 수 있게 하는 옵션이므로, 믿을 수 있는 파일에만 사용해야 합니다.

### 2. 여러 입력을 합치는 앙상블 모델

`keras69_ensemble1.py`은 `(100, 2)` 입력과 `(100, 3)` 입력을 따로 처리합니다. 여기서 첫 번째 `100`은 데이터 묶음 안에 샘플이 100개 있다는 뜻입니다. 두 번째 숫자 `2`와 `3`은 샘플 하나가 가진 feature 개수입니다.

각 입력 가지가 계산을 끝내면 출력은 각각 `(batch, 80)`과 `(batch, 40)`이 됩니다. `Concatenate`는 같은 샘플의 결과를 옆으로 이어 붙이므로 결과는 `(batch, 120)`입니다. 이어서 Dense 층을 통과하고 최종 `Dense(1)`이 하나의 값을 예측합니다.

`train_test_split`에 여러 입력과 정답을 함께 넣는 이유는 같은 샘플이 함께 train/test로 이동하게 하기 위해서입니다. 예를 들어 첫 번째 회사 주가와 같은 날짜의 환율, 그 날짜의 정답 온도가 서로 다른 행으로 섞이면 모델은 틀린 문제와 답을 연결하게 됩니다.

### 3. 다중 입력·다중 출력의 순서

`keras69_ensemble3.py`은 세 입력 가지를 합친 뒤 출력 가지를 두 개로 나눕니다. 모델이 `outputs=[last_output1, last_output2]`라면 `fit()`의 정답도 `[y1_train, y2_train]` 순서여야 합니다. 순서가 바뀌면 첫 번째 출력이 두 번째 정답을 배우려는 문제가 생깁니다.

`last_dense1`과 `last_dense2`를 만들었지만 `last_output1 = Dense(1)(merge3)`가 `merge3`에서 바로 시작합니다. 따라서 이름만 만든 `last_dense1`, `last_dense2`는 최종 출력 경로에 연결되지 않았고 현재 계산에 사용되지 않습니다. 층을 만들었다는 사실과 모델 출력에 연결했다는 사실은 다릅니다.

## 반드시 기억할 점

1. RAG의 순서는 문서 읽기 → 조각 나누기 → 임베딩 → 벡터 저장·검색 → prompt에 context 넣기 → LLM 답변입니다.
2. NumPy의 `.T`는 행과 열을 바꿉니다. `np.array([range(100), range(301, 401)]).T`의 shape는 `(100, 2)`입니다.
3. `Concatenate`는 보통 마지막 축을 이어 붙입니다. `(batch, 80)`과 `(batch, 40)`은 `(batch, 120)`이 됩니다.
4. 다중 입력 데이터는 첫 번째 축의 샘플 순서가 서로 대응해야 합니다.
5. 다중 출력 모델의 출력 목록과 정답 목록의 순서는 반드시 일치해야 합니다.
6. 만든 Keras 층이 최종 출력 경로에 연결되어 있는지 확인해야 합니다.
7. 코드 주석의 loss·predict 숫자는 현재 실행 결과가 아닐 수 있습니다. 실제 실행 여부와 정적 코드 확인을 구분해야 합니다.
8. pandas의 `axis=1`은 열 방향입니다. 오늘의 신규 코드는 pandas를 직접 실행하지 않았으므로 DataFrame 결과를 사실처럼 말하면 안 됩니다.
9. `allow_dangerous_deserialization=True`는 신뢰 경계를 약하게 만들 수 있으므로 출처가 확실한 저장 파일에서만 사용해야 합니다.

## Python·NumPy·pandas 연결

- Python: `answer_invoke(message, history)`처럼 함수의 입력과 반환값을 확인해야 합니다. RAG 함수는 `response['answer']`를 반환합니다.
- NumPy: `.T`는 배열의 축 순서를 바꾸며, 배열의 행 수는 샘플 수로 사용됩니다.
- pandas: `df.drop([target], axis=1)`처럼 `axis=1`은 열을 뜻합니다. 다만 오늘 코드에는 pandas 실행이 없으므로 pandas 동작은 일반 원리로만 설명했습니다.
