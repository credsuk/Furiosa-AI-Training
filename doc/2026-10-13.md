## 주제

오늘은 새 Python 학습 파일이 추가되지 않았으므로, 최신 학습 코드의 핵심 흐름을 다른 문제 형태로 복습한다.

1. RAG에서 검색 문서와 대화 기록을 함께 prompt에 넣는 흐름
2. Keras 다중 출력 모델의 출력 경로와 정답 순서
3. 주가 시계열의 날짜 정렬, 20일 window, train-only scaling
4. Python·NumPy·pandas 기초: `to_numpy()`, `reshape()`, `axis=1`, 3차원 shape

## 중요한 내용

- `reg21_Gradio_history.py`는 FAISS에서 가까운 문서 2개를 찾고, Gradio `history`를 `HumanMessage`·`AIMessage` 목록으로 바꾼 뒤 현재 질문과 함께 `rag_chain`에 전달한다. `MessagesPlaceholder`는 이 목록이 들어갈 자리이다.
- `keras69_ensemble4.py`의 실제 모델 출력은 `merge3`에서 바로 나온 `last_output1`, `last_output2` 두 개이다. `last_dense1`, `last_dense2`, `merge2`는 정의되었지만 최종 출력 경로에 연결되지 않았다.
- `keras70_1_주가맞추기.py`는 세 종목의 날짜를 맞춘 뒤 20일 window를 만들고, 앞 80%를 train, 뒤 20%를 test로 나눈다. X scaler와 y scaler는 train 데이터로만 `fit()`한다.
- `(샘플, 20, 6)`은 20일을 한 묶음으로 보고, 각 날짜마다 feature 6개가 있다는 뜻이다. `reshape(-1, feature 수)`로 scaling한 뒤 원래 3차원 shape로 되돌린다.

## 반드시 기억할 점

- 검색기(retriever)는 자료를 찾고, LLM은 자료·대화·질문을 이용해 답을 만든다.
- 다중 출력은 모델 출력 순서와 y 목록 순서를 맞춰야 한다.
- 층을 선언했는지보다 계산 그래프의 최종 출력에 연결했는지가 중요하다.
- 시계열은 시간 순서를 보존하고, 테스트 정보를 scaler 학습에 섞지 않는다.
- 코드 주석의 loss와 예측값은 이번 실행에서 재현한 결과가 아니다.

## 코드 흐름과 shape 설명

1. RAG: 임베딩 모델 → FAISS 로드 → `k=2` 검색 → prompt에 context/history/input 삽입 → 답변.
2. 다중 출력: `(batch, 2)` 입력 → Dense 층 → `merge3` → 두 개의 `(batch, 1)` 출력.
3. 주가: 종목별 DataFrame 정렬·날짜 정합 → `(window 수, 20, feature 수)` 생성 → 시간 기준 분할 → scaling → LSTM 두 가지와 Conv1D 한 가지를 Concatenate → `(batch, 1)` 예측.

## 쉬운 예시

세 친구의 일기를 비교할 때 날짜가 같은 줄끼리 맞춰야 한다. 그 뒤 20일씩 묶어 모델에게 보여주고, 시험용 마지막 기간은 공부할 때 미리 보지 않는다. 여러 출력 모델은 한 선생님이 두 과목 점수를 따로 내는 것과 같아서, 첫 번째 답은 첫 번째 출력에, 두 번째 답은 두 번째 출력에 맞춰야 한다.
