#### **Embdedding**

임베딩(Embedding)은 인간의 언어, 이미지, 오디오 같은 복잡하고 비정형화된 데이터를 기계가 이해하고 처리할 수 있도록 **숫자의 나열인 벡터(Vector)로 변환하는 기술**

데이터 전처리

**언어 모델의 경우 길이가 다 다르다 그러게 길이를 맞춰**야한다

맞춰주는 가장 쉬운 방법

빈자리를 0으로 채운다

\> 이렇게 shape가 맞출 수 있다

\> 조선말은 끝까지들어봐야한다 즉, 중요한건 뒤에 있다 

\> 근데 뒷자리를 0으로 빈자리를 채우면 0에 수렴된다

\> 그래서 0을 앞부터 채워야 한다

이걸 **padding**이라고 한다 우리는 이미지(cnn)할때 했었다

하지만 일부러 뒤에 채울 경우도 있다 그래서 padding옵션이 2개가 있다

**문장이 너무 길면 자른다**

```
############### 패딩 ###############
from tensorflow.keras.preprocessing.sequence import pad_sequences
padded_x = pad_sequences(
    x, # 타켓할 데이터
    padding='pre', # pre앞을 0으로 채운다 / post 뒤를 0으로 채울때
    maxlen = 5, # 최대길이 세팅
    truncating='pre' # 최대길이가 넘어가면 어디를 짜를지 정한다 / 디폴트가 앞(pre)이다
)

print(padded_x)
print(padded_x.shape) # (15, 5)
```

from tensorflow.keras.layers import Dense, Embedding, SimpleRNN

model = Sequential()

model.add(Embedding(
    # input_dim=30, # 단어사전의 갯수 / 크게 작성해도 알아서 맞춤  /  입력 데이터의 단어 집합(vocabulary) 크기 
    input_dim=np.max(padded_x),

    input_length=padded_x.shape[1], #

import _llm

prompt = "삼성전자의 창업주는 누구인가요?"

from langchain_openai import OpenAIEmbeddings
embeddings = OpenAIEmbeddings(
    model="text-embedding-3-small", # 임베딩을 해주는 모델 끝날때까지 이거쓰면 충분
    api_key=_llm.api_key,
    base_url=_llm.base_url,
)

vector = embeddings.embed_query(prompt)
print(vector)
print("======================================")
print("임베딩 벡터의 차원 : ", len(vector)) # 임베딩 벡터의 차원 :  1536
