## shape 변화와 핵심 개념

- `Tokenizer` 결과는 문장별 정수 리스트이므로 길이가 서로 다를 수 있습니다.
- `pad_sequences(..., maxlen=5, padding='pre', truncating='pre')`는 짧은 문장 앞에 0을 붙이고 긴 문장의 앞부분을 잘라 `(15, 5)`처럼 맞춥니다. `padding`과 `truncating`은 서로 다른 옵션입니다.
- 정수 토큰 입력이 `(batch, timestep)`이고 `Embedding(output_dim=10)`이면 출력은 `(batch, timestep, 10)`입니다. `SimpleRNN(10)`이 마지막 상태만 반환하면 `(batch, 10)`입니다.
- one-hot은 vocabulary 축을 추가해 희소한 큰 벡터가 될 수 있습니다. Embedding은 각 token ID를 학습 가능한 밀집 벡터로 바꿉니다. 실제 품질·학습 결과는 실행하지 않았으므로 단정하지 않습니다.
- `input_dim`은 token ID가 표현될 vocabulary 크기와 맞아야 합니다. 코드의 `np.max(padded_x)` 사용은 0 padding과 최대 token ID의 관계를 별도로 점검해야 하며, 실제 모델 실행은 확인하지 않았습니다.

## 반드시 기억할 사항

1. 문장별 token sequence 길이는 다를 수 있어 모델 입력 전에 padding/truncating이 필요합니다.
2. 학습과 예측의 tokenizer, `maxlen`, `padding`, `truncating` 규칙은 같아야 합니다.
3. Embedding은 `(batch, timestep)`을 마지막 embedding 차원이 추가된 3차원 텐서로 변환합니다.
4. one-hot은 범주형 라벨·작은 범주 데이터에 편리하지만 vocabulary가 커지면 비효율적일 수 있습니다. Embedding은 token ID 입력을 밀집 벡터로 바꿉니다.
5. API key는 코드에 직접 기록하거나 출력하지 말고 환경변수·비밀 저장소를 사용해야 합니다.

## 초보자용 Python·NumPy·pandas 연결

### Python

`fit_on_texts`, `texts_to_sequences`, `embed_query`는 객체의 메서드 호출입니다. `maxlen=5` 같은 keyword argument는 함수의 특정 옵션을 이름으로 지정합니다. `getEmbedding(prompt)`은 입력을 받아 `embed_query`의 결과를 `return`하는 함수입니다.

### NumPy

`padded_x.shape == (15, 5)`는 15개 샘플과 5개 timestep을 뜻합니다. Embedding의 `output_dim=10`은 각 timestep을 길이 10의 벡터로 바꾸므로 `(15, 5, 10)`이 됩니다. `reshape`는 원소 수를 보존해야 하며, 이번 day21 코드에서 실행으로 확인한 reshape 결과는 없습니다.

### pandas

이번 day21의 핵심 실행 코드는 pandas DataFrame을 사용하지 않았습니다. 따라서 `read_csv`, `loc/iloc`, `groupby`, 결측치 처리는 이 날짜 기준 `확인 불가`입니다. 단어 token sequence와 pandas의 범주형 열 처리는 같은 것으로 단정하면 안 됩니다.
