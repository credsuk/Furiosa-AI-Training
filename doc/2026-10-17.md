오늘 새로 추가된 학습 코드는 없었다. 가장 최근 학습 코드인 RAG 검색 예제를 실제 파일과 주석까지 다시 읽고 다음 내용을 복습했다.

3. 임베딩, FAISS 벡터 저장소, retriever의 연결
4. BM25 키워드 검색과 벡터 검색의 차이
5. `EnsembleRetriever`를 이용한 하이브리드 검색
6. Gradio 대화 기록을 `HumanMessage`와 `AIMessage`로 바꾸는 흐름

## 중요한 내용

- RAG는 질문에 바로 답을 지어내게 하는 대신, 먼저 관련 문서를 찾고 그 문서를 LLM의 참고 자료로 넣는 방식이다.
- `Document`는 본문인 `page_content`와 출처 같은 부가 정보인 `metadata`를 담는다.
- 청킹은 긴 문서를 검색하기 쉬운 작은 조각으로 나누는 과정이다. `chunk_overlap=100`은 이웃 조각의 일부를 겹치게 하여 경계에서 문맥이 끊기는 일을 줄이는 설정이다.
- 임베딩은 글을 숫자 벡터로 바꾸는 일이다. FAISS는 질문 벡터와 문서 벡터의 거리를 비교해 가까운 문서를 찾는다.
- BM25는 질문과 문서에 같은 단어가 얼마나 나타나는지에 강한 검색이다. 벡터 검색은 단어가 달라도 의미가 비슷한 내용을 찾는 데 도움을 준다.
- `EnsembleRetriever`는 BM25와 벡터 retriever를 함께 사용한다. 코드의 `weights=[0.5, 0.5]`는 두 검색기의 결합 가중치를 같게 둔 설정이다.
- `MessagesPlaceholder(variable_name="chat_history")`는 이전 메시지를 프롬프트에 끼워 넣을 자리다. 이것은 현재 요청에 대화 기록을 전달하는 것이며, 모델의 영구 기억을 자동으로 만드는 기능은 아니다.
- `similarity_score_threshold`의 점수 방향과 범위는 벡터 저장소와 거리 설정을 확인해야 한다. 코드 주석의 `0.7`을 모든 검색기에서 같은 의미라고 단정하면 안 된다.

- `FAISS.load_local(..., allow_dangerous_deserialization=True)`는 신뢰할 수 있는 저장 파일에만 사용해야 한다.

- `RAG/rag22_Gradio_1_doc_check.py`의 PDF 이름은 `Attention_is_all_you_need.pdf`이고, `rag23_02`와 `rag23_03`은 `Attention Is All You Need.pdf`를 사용한다. Linux는 파일명 대소문자와 밑줄·공백을 구별하므로 실제 파일명과 코드가 일치해야 한다.

## 코드 흐름과 shape 설명

1. `PyPDFLoader`가 PDF 페이지를 `Document` 객체의 리스트로 읽는다.
2. splitter가 각 문서를 여러 문자열 청크로 나눈다.
3. 임베딩 모델이 문서 청크와 질문을 같은 길이의 숫자 벡터로 바꾼다.
4. FAISS가 벡터를 저장하고 질문과 가까운 벡터를 검색한다.
5. retriever가 검색된 `Document` 리스트를 반환한다.
6. `create_retrieval_chain`이 검색 결과를 document chain에 전달한다.
7. 프롬프트가 `context`, `chat_history`, 현재 `input`을 묶고 LLM이 답변을 만든다.
8. Gradio의 `history` 각 항목에서 `role`과 `content`를 읽어 이전 사용자 메시지는 `HumanMessage`, 이전 답변은 `AIMessage`로 변환한다.

문서 청크는 문자열이고 검색 결과는 `Document` 리스트다. 임베딩은 보통 `(문서 수, 임베딩 차원)`처럼 생각할 수 있는 벡터 모음이다. 실제 문서 수와 차원은 실행한 파일·모델에 따라 확인해야 하며, 코드 주석의 15, 205, 1536은 이번 실행 결과가 아니다.

## 쉬운 예시

도서관에서 질문한다고 생각하자. BM25 사서는 질문에 나온 단어가 책에 얼마나 많이 있는지 센다. 벡터 사서는 자동차와 차량처럼 단어가 달라도 뜻이 가까운 책을 찾는다. 두 사서가 찾은 내용을 선생님(LLM)에게 보여 주면, 선생님은 그 자료를 참고해 답한다. 자료가 없는데도 답을 만들면 틀릴 수 있으므로, 검색된 자료가 정말 질문과 관련 있는지 확인해야 한다.
