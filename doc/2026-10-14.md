## 주제

오늘은 Keras 애플리케이션 모델과 전이 학습(Transfer Learning)을 공부했다.

1. VGG16의 `include_top`과 입력 shape
2. ImageNet으로 미리 학습된 특징 추출기와 새 분류기 붙이기
3. `trainable=False`로 가중치 동결하기
4. 일부 층만 선택해 동결하는 부분 동결
5. CIFAR-10·CIFAR-100에서 여러 사전 학습 모델을 비교하는 흐름

## 중요한 내용

- `include_top=True`는 VGG16의 기존 분류기까지 포함하므로 보통 ImageNet용 입력 크기와 1000개 분류 구조를 그대로 사용한다. `include_top=False`는 마지막 분류기를 빼고 합성곱 기반 특징 추출기만 가져오므로 뒤에 내 데이터에 맞는 분류기를 붙일 수 있다.
- `weights='imagenet'`은 ImageNet으로 학습된 가중치를 사용한다는 뜻이다. 가중치는 이미지의 선·색·무늬처럼 일반적인 특징을 이미 배운 값이다.
- `vgg16.trainable = False`는 VGG16 안의 가중치를 학습 중 바꾸지 않게 한다. 이후 추가한 `Flatten`, `Dense` 층은 기본적으로 학습 가능하므로 새 분류기만 학습하는 구조가 된다.
- `model.layers[i].trainable = False` 또는 층 생성 때 `trainable=False`로 일부 층을 동결할 수 있다. 설정을 바꾼 뒤에는 일반적으로 다시 `compile()`해야 변경된 trainable 상태가 학습에 반영된다.
- `GlobalAveragePooling2D`는 `(높이, 너비, 채널)` 특징 맵을 채널별 평균으로 줄여 `Flatten`보다 파라미터를 크게 늘리지 않고 분류기로 넘기는 방법이다.
- `keras73`과 `keras76` 코드는 CIFAR 이미지의 픽셀을 `255.`로 나누고, 사전 학습 모델을 동결한 뒤 새 Dense 분류기를 학습한다. CIFAR-10은 마지막 Dense가 10개, CIFAR-100은 100개이다.

## 반드시 기억할 점

- 사전 학습 모델은 선생님이 이미 배운 특징 추출기이고, 마지막 Dense 층은 새 시험의 답안 분류기이다.
- `weights`는 어떤 학습 결과를 가져올지, `trainable`은 학습 중 그 값을 바꿀지를 정한다.
- `include_top=False`만으로 가중치가 동결되는 것은 아니다. 동결은 별도로 `trainable=False`를 설정해야 한다.
- `model.weights`와 `model.trainable_weights`는 다르다. 전자는 전체 가중치, 후자는 현재 업데이트될 가중치이다.
- 학습 출력처럼 주석에 적힌 loss·accuracy는 코드에 기록된 과거 실행 결과일 수 있다. 이번 작업에서 TensorFlow 학습을 다시 실행한 결과로 단정하지 않는다.

## 코드 흐름과 shape 설명

1. CIFAR 데이터는 `(샘플 수, 32, 32, 3)` 형태로 읽고 `255.`로 나누어 픽셀 범위를 대략 0~1로 만든다.
2. `VGG16(include_top=False, input_shape=(32, 32, 3))`은 입력 이미지에서 특징 맵을 만든다.
3. VGG16을 동결한 뒤 `GlobalAveragePooling2D` 또는 `Flatten`을 거쳐 Dense 층으로 보낸다.
4. 마지막 Dense의 출력 수를 클래스 수에 맞추고 `softmax`로 각 클래스 확률을 만든다.
5. `sparse_categorical_crossentropy`는 정수 라벨을 사용하는 다중 분류 손실이다. 학습 후 `evaluate()`로 시험 데이터를 평가하고, 필요하면 `argmax(axis=1)`로 가장 큰 확률의 클래스 번호를 고른다.
