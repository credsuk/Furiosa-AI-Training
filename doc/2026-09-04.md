
## 학습 보강: 제출 파일의 계약

### Python 문법 반복

`model.predict(test)`의 반환값을 `pred` 변수에 저장한 뒤 DataFrame 열에 대입하는 것은 “함수 반환값 → 변수 → 파일” 흐름입니다. 파일 저장 함수의 옵션도 명시적으로 확인합니다.

### NumPy 핵심

예측 결과가 `(n, 1)`이면 제출 열에 넣기 전에 `pred.reshape(-1)` 또는 `pred.ravel()`이 필요한 경우가 있습니다. 두 함수 모두 1차원으로 펴지만, 변환 전후 shape를 확인해야 합니다.

### pandas 핵심

제출 파일은 보통 `sample_submission`의 열 구조를 기준으로 만듭니다. `submission['count'] = pred`처럼 열을 대입할 때는 pred의 길이가 submission 행 수와 같아야 합니다. `to_csv(index=False)`는 DataFrame 인덱스를 별도 열로 저장하지 않는다는 뜻입니다.

```python
submission = pd.read_csv('sampleSubmission.csv')
submission['count'] = pred.reshape(-1)
submission.to_csv('submission.csv', index=False)
```

### 반복해서 기억할 점

검증 점수와 제출 결과는 같은 목적이 아닙니다. 제출 전 열 이름, 행 수, 결측치, 원본 test 순서를 확인합니다.
