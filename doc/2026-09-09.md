## 이날의 주제: 다중 분류와 One-hot·Softmax

Iris·Wine·Covtype 데이터에 One-hot 정답, softmax 출력, categorical_crossentropy를 적용했습니다.

## 반드시 기억할 내용

softmax 출력 노드 수는 클래스 수와 같아야 하고, one-hot y의 열 수와 일치해야 합니다.

```text
클래스 3개 → y.shape[1] = 3 → Dense(3, softmax)
```

## 학습 보강: 다중 분류와 배열 차원

### Python 문법 반복

`y = to_categorical(y)`처럼 반환값을 다시 같은 이름에 대입하면 기존 변수의 의미가 바뀝니다. 변환 전·후의 자료형과 shape를 출력해 확인합니다.

### NumPy 핵심

`np.argmax(prob, axis=1)`은 각 샘플의 클래스 축에서 가장 큰 확률의 위치를 반환합니다. `axis=1`을 빼면 전체 배열에서 하나의 위치만 찾으므로 다중 샘플 예측에서는 축을 명시해야 합니다.

### pandas 확인

Iris·Wine·Covtype의 원본 표를 DataFrame으로 읽었다면 feature 열과 target 열을 분리한 뒤, one-hot 변환은 target에만 적용합니다. pandas 열 선택 결과가 Series인지 DataFrame인지에 따라 shape가 달라질 수 있습니다.

### 반복해서 기억할 점

클래스가 3개면 one-hot y의 열도 3개이고 마지막 Dense 노드도 3개입니다. softmax의 각 행 확률 합이 1에 가까운지 작은 출력으로 확인합니다.
