## 학습 보강: 날짜별 문서 작성 규칙

### Python 문법 반복

날짜별 파일을 다룰 때는 날짜 문자열을 파일명에 넣고, 파일이 이미 존재하는지 먼저 확인한 뒤 새 파일만 생성해야 합니다. 기존 사용자의 내용을 보존하는 것이 자동화의 기본 조건입니다.

### NumPy·pandas 반복

이날은 문서 체계 변경이 중심이라 NumPy·pandas 코드 변경은 확인되지 않았습니다. 앞으로 실제 코드에 NumPy 함수나 pandas 처리가 등장하면 함수의 입력·반환값·shape를 작은 예제로 함께 기록합니다.

### 반복해서 기억할 점

문서에는 commit 여부와 학습 내용의 근거를 구분해 적습니다. commit이 없으면 없다고 기록하고, 실제로 읽은 파일과 실행 결과만 학습 사실로 정리합니다.
