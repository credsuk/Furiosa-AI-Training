## 학습 보강: CSV와 결측치 처리

### Python 문법 반복

`X = train.drop(columns=['count'])`는 원본 DataFrame의 특정 열을 제외한 결과를 새 변수에 저장하는 대입문입니다. 함수가 원본을 바꾸는지 새 객체를 반환하는지는 pandas 메서드마다 다르므로 결과를 변수에 받아 확인하는 습관이 중요합니다.

### NumPy 핵심

모델에 넣기 전 `np.asarray(X)` 또는 DataFrame의 `to_numpy()`로 배열을 만들 수 있습니다. 변환 후 `dtype`와 `shape`를 확인하고, 숫자열에 문자열이 섞이면 연산 전에 자료형을 점검합니다.

### pandas 핵심

`pd.read_csv()`는 CSV를 DataFrame으로 읽습니다. `df.isna().sum()`은 열별 결측치 개수를 반환하고, `dropna()`는 결측 행을 제거한 새 DataFrame을 반환합니다. target을 분리할 때는 `X = df.drop(columns=['count'])`, `y = df['count']`처럼 입력과 정답을 명확히 나눕니다.

```python
train = pd.read_csv('train.csv')
print(train.shape)
print(train.isna().sum())
X = train.drop(columns=['count'])
y = train['count']
```
