## 이날의 주제: RNN·GRU·LSTM과 window 분할

LSTM/GRU 구조, 시계열 window 분할, 다중 feature 입력 `(샘플, 4, 2)`, 다음 값 예측을 구현했습니다.

## 반드시 기억할 내용

window 길이 `timestep`이면 앞 구간을 X, 다음 값을 y로 만듭니다. LSTM은 hidden state와 cell state를 사용하고 GRU는 별도 cell state 없이 hidden state를 게이트로 조정합니다.

```text
[과거 t개 값] → X
[그 다음 값]   → y
X.shape = (샘플, timestep, feature)
```

## 학습 보강: window·reshape·다중 feature

### Python 문법 반복

`def split_x(data, size):`처럼 함수를 만들면 반복되는 window 로직을 재사용할 수 있습니다. `return x, y`는 두 값을 tuple로 반환하며 호출부에서 `x, y = split_x(...)`로 동시에 받을 수 있습니다.

### NumPy 핵심

`bbb[:, :-1]`은 모든 행에서 마지막 열을 제외하고, `bbb[:, -1:]`은 마지막 열을 2차원으로 유지합니다. `-1`과 `-1:`은 결과 차원이 다를 수 있으므로 shape를 출력해 확인합니다.

```python
x = windows[:, :-1]
y = windows[:, -1:]
print(x.shape, y.shape)
```

### pandas 핵심

다중 feature 시계열을 DataFrame에서 만들었다면 `df.iloc[i:i+size].to_numpy()`로 window를 구성할 수 있습니다. 시간 열을 feature로 포함할지 제외할지 먼저 결정합니다.

### 반복해서 기억할 점

RNN 입력은 `(샘플, timestep, feature)`이며 `input_shape`에는 샘플 수를 넣지 않습니다. `y[:, 0, 1]`은 각 샘플의 첫 timestep에서 두 번째 feature를 선택하는 표현이므로 target 위치를 코드와 함께 추적합니다.

## 개인 기록 정리

### 전체 학습 흐름

사용자는 지금까지의 학습을 다음 흐름으로 정리했습니다.

```text
데이터 → 모델 구성 → compile·훈련 → 평가·예측
```

모델보다 데이터의 품질과 구조가 더 중요할 수 있다는 점, 그리고 같은 데이터라도 shape를 모델이 기대하는 형태로 맞추는 과정이 중요하다는 점을 기억하고 있습니다.

### 이번에 다시 확인해야 할 개념

- `batch_size`: 전체 행을 한 번에 처리하지 않고 batch 단위로 나누어 가중치를 업데이트합니다. 예를 들어 100행을 batch size 8로 처리하면 마지막 batch를 포함해 약 13개의 batch가 됩니다. batch size가 과적합에 영향을 줄 수 있다는 메모는 가능성으로 이해하고, 실제 효과는 데이터와 실험으로 확인합니다.
- train/test와 validation: train만 확인하면 과적합을 놓칠 수 있으므로 validation loss와 test 성능을 구분합니다. EarlyStopping은 보통 `val_loss` 같은 지표를 감시해 학습을 멈추거나 best weight를 복원합니다.
- 분류: 이진 분류는 보통 `sigmoid`와 `binary_crossentropy`, 다중 분류는 one-hot label·`softmax`·`categorical_crossentropy`를 사용합니다.
- 스케일링: MinMax, Standard, Robust 등은 데이터 분포에 따라 비교해야 하며, scaler는 train에 fit한 뒤 validation/test에는 transform만 적용합니다.
- 저장과 정규화: ModelCheckpoint, weight 저장·복원, Dropout의 학습 시/평가 시 동작 차이를 다시 반복합니다.

### RNN·NumPy에서 특히 어려웠던 부분

RNN 입력의 기본 shape는 `(batch_size, timestep, feature)`이며, `units`는 출력 차원과 연결됩니다. 과거 데이터를 window로 자르는 것이 이번 학습의 핵심입니다.

```python
def split_x(dataset, timestep):
    x, y = [], []
    timestep = timestep + 1
    for i in range(len(dataset) - timestep):
        subset = dataset[i:i + timestep]
        x.append(subset[:-1])
        y.append(subset[-1:])
    return np.array(x), np.array(y)
```

`x = bbb[:, :-1]`은 모든 샘플에서 마지막 timestep을 제외하고, `y = bbb[:, -1:]`은 마지막 값을 2차원으로 유지합니다. 다중 feature에서 `y = y[:, 0, 1]`은 첫 timestep의 두 번째 feature를 선택해 `(샘플,)` 형태로 줄이는 표현입니다. `-1`과 `-1:`의 차원 차이, `axis`와 슬라이싱을 작은 배열로 계속 연습해야 합니다.

### 확인이 필요한 메모

- RNN·LSTM·GRU의 내부 gate와 파라미터 수는 모델 종류와 units·feature·return_sequences 설정에 따라 계산해야 하므로 단순한 문장으로 외우지 않습니다.
- “LSTM을 여러 층 쌓으면 항상 좋다”거나 “GRU가 항상 더 빠르고 좋다”라고 일반화하지 않습니다. 데이터와 목적에 따라 실험합니다.
- `Non-trainable params`는 동결된 가중치나 전이학습 맥락에서 다시 확인합니다.
- TensorFlow와 PyTorch, 구버전 강의 코드와 현재 API 차이는 별도 확인 항목으로 남깁니다.
- 파라미터 수, 이미지 정규화 범위, 144개 timestep을 사용하는 실제 시계열 분할은 코드와 실행 결과로 검증합니다.
