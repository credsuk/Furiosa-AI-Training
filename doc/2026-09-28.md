## 이날의 주제: RNN·GRU·LSTM과 window 분할

LSTM/GRU 구조, 시계열 window 분할, 다중 feature 입력 `(샘플, 4, 2)`, 다음 값 예측을 구현했습니다.

## 반드시 기억할 내용

window 길이 `timestep`이면 앞 구간을 X, 다음 값을 y로 만듭니다. LSTM은 hidden state와 cell state를 사용하고 GRU는 별도 cell state 없이 hidden state를 게이트로 조정합니다.

```text
[과거 t개 값] → X
[그 다음 값]   → y
X.shape = (샘플, timestep, feature)
```

## 학습 보강: window·reshape·다중 feature

### Python 문법 반복

`def split_x(data, size):`처럼 함수를 만들면 반복되는 window 로직을 재사용할 수 있습니다. `return x, y`는 두 값을 tuple로 반환하며 호출부에서 `x, y = split_x(...)`로 동시에 받을 수 있습니다.

### NumPy 핵심

`bbb[:, :-1]`은 모든 행에서 마지막 열을 제외하고, `bbb[:, -1:]`은 마지막 열을 2차원으로 유지합니다. `-1`과 `-1:`은 결과 차원이 다를 수 있으므로 shape를 출력해 확인합니다.

```python
x = windows[:, :-1]
y = windows[:, -1:]
print(x.shape, y.shape)
```

### pandas 핵심

다중 feature 시계열을 DataFrame에서 만들었다면 `df.iloc[i:i+size].to_numpy()`로 window를 구성할 수 있습니다. 시간 열을 feature로 포함할지 제외할지 먼저 결정합니다.

### 반복해서 기억할 점

RNN 입력은 `(샘플, timestep, feature)`이며 `input_shape`에는 샘플 수를 넣지 않습니다. `y[:, 0, 1]`은 각 샘플의 첫 timestep에서 두 번째 feature를 선택하는 표현이므로 target 위치를 코드와 함께 추적합니다.
