## 코드 흐름

```text
정수 label ── sparse_categorical_crossentropy ── softmax 출력
one-hot label ─ categorical_crossentropy ─────── softmax 출력

이미지 (batch, height, width[, channel])
  → 정규화
  → Reshape 또는 channel 추가
  → CNN
  → GlobalAveragePooling/Flatten
  → Dense 분류

표 데이터 (batch, feature)
  → scaler.fit_transform(train)
  → scaler.transform(test)
  → reshape(batch, timestep, feature)
  → LSTM/GRU
  → Dense 회귀·분류 출력
```

## 핵심 shape

- MNIST 원본은 `(60000, 28, 28)`이고 CNN 입력은 `(60000, 28, 28, 1)`입니다.
- CIFAR 입력은 `(50000, 32, 32, 3)`처럼 RGB channel을 이미 포함합니다.
- `keras65_Reshape2.py`의 합성곱 결과 `(batch, 23, 23, 16)`은 `Reshape((23*23, 16))` 뒤 `(batch, 529, 16)`이 됩니다.
- 이때 LSTM의 `input_shape=(529, 16)`에서 529는 timestep, 16은 feature입니다.
- `reshape(-1, 4, 2)`는 전체 원소 수를 보존하고, 앞 축을 자동 계산하여 4 timestep·2 feature로 해석합니다.

## 반드시 기억할 내용

1. 정수 class label이면 sparse loss, one-hot label이면 categorical loss를 우선 검토합니다.
2. 마지막 activation의 unit 수가 class 수와 맞아야 합니다.
3. `Reshape`는 원소 수를 보존하며 데이터의 의미와 순서를 바꾸지 않습니다.
4. scaler는 train에서만 `fit`하고 test에는 동일한 scaler로 `transform`합니다.
5. 평가 입력과 정답의 샘플 수, 예측과 정답의 shape를 실제 값으로 확인합니다.

## Python·NumPy·pandas 초보자 보강

- `pd.get_dummies(y)`는 label의 각 class를 별도 열로 만드는 DataFrame 변환입니다. 행 수는 유지되고 열 수는 관측 class 수에 따라 달라집니다.
- `drop([...], axis=1)`의 `axis=1`은 열 방향 삭제입니다. `axis=0`은 행 방향입니다.
- NumPy의 `reshape`는 총 원소 수가 같아야 합니다. `-1`은 다른 축과 원소 수를 바탕으로 자동 계산되는 한 축입니다.
- `fit_transform`은 기준을 학습한 뒤 변환하고, `transform`은 이미 학습한 기준만 적용합니다.
