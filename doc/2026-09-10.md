## 이날의 주제: 스케일링과 입력 shape 점검

Santander·Digits 등을 포함해 MinMax, Standard, MaxAbs, Robust scaler를 비교하고 모델 input_shape를 정리했습니다.

## 반드시 기억할 내용

scaler는 train에만 fit하고 test에는 같은 scaler로 transform해야 합니다. test까지 fit하면 데이터 누수가 생깁니다.

```text
fit(train) → transform(train)
             └→ transform(test)
```

## 학습 보강: scaler와 데이터 누수

### Python 문법 반복

`scaler.fit(X_train)`과 `scaler.transform(X_test)`는 각각 메서드 호출입니다. `fit_transform(X_train)`은 학습 데이터에 fit과 transform을 연속 적용하는 편의 메서드입니다.

### NumPy 핵심

스케일링 전후 `X.min(axis=0)`, `X.max(axis=0)`로 feature별 범위를 비교할 수 있습니다. `axis=0`을 사용해야 열별 feature 통계를 계산합니다.

### pandas 핵심

DataFrame에 scaler 결과를 다시 넣을 때 행·열 순서가 유지되는지 확인합니다. `df.select_dtypes(include='number')`는 숫자 열을 선택하지만, target이나 ID를 실수로 포함할 수 있으므로 열 목록을 직접 확인합니다.

### 반복해서 기억할 점

scaler는 train에만 fit하고 validation/test에는 같은 scaler로 transform합니다. test 통계가 학습에 들어가면 데이터 누수입니다. `input_shape`에는 batch 크기를 넣지 않고 feature 구조만 넣습니다.
