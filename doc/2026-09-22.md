## 이날의 주제: ImageDataGenerator 이미지 증강

Fashion-MNIST·MNIST·CIFAR10/100과 사람 이미지에 회전·이동·확대 등 이미지 증강을 적용했습니다.

## 반드시 기억할 내용

증강은 train 데이터 다양성을 늘리는 데 사용하고 validation/test는 실제 분포 평가를 위해 함부로 증강하지 않습니다.

```text
원본 train 이미지 → 여러 변형 이미지 → CNN 학습
검증/test → 원래 분포 유지
```

## 학습 보강: ImageDataGenerator와 데이터 분리

### Python 문법 반복

generator는 한 번에 전체 데이터를 반환하지 않고 반복해서 batch를 제공합니다. `for batch_x, batch_y in generator:`처럼 반환되는 두 값을 각각 받는 구조를 이해합니다.

### NumPy 핵심

증강 전후 batch의 shape는 보통 `(batch, height, width, channel)`로 같습니다. `rotation_range` 같은 옵션은 값 자체를 바꾸지만 label shape는 유지해야 합니다.

### pandas 확인

이미지 경로·라벨 CSV를 generator에 연결할 때 DataFrame의 label 자료형과 클래스 이름을 확인합니다. validation/test에는 train용 무작위 증강을 적용하지 않는지 설정을 분리합니다.

### 반복해서 기억할 점

증강은 train의 다양성을 늘리는 도구이지 validation/test를 변형하는 절차가 아닙니다. 실제 입력 batch와 label을 한 번 출력해 설정을 검증합니다.
