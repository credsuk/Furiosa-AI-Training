# 일자별 학습 정리

이 디렉터리에는 매일 저녁 20:00(KST)에 생성되는 학습 정리 문서를 저장합니다.

## 파일 형식

```text
doc/YYYY-MM-DD.md
```

각 문서에는 다음 내용을 포함합니다.

- 해당 날짜의 commit 메시지와 변경 파일(실제 commit이 없으면 작업 트리와 학습 파일 기준으로 기록)
- 그날 학습한 중심 주제의 상세 설명과 코드 흐름
- 반드시 기억해야 할 핵심 내용과 헷갈리기 쉬운 비교
- Python 문법, NumPy 함수·배열 연산, pandas 처리 중 해당 날짜에 등장한 부분
- 아직 익숙하지 않은 Python·NumPy·pandas 개념의 반복 설명과 작은 실행 예제
- 코드의 입력·출력·자료형·shape·인덱싱·반환값 확인
- 사용자가 별도로 작성한 날짜별 메모의 요점과 기존 학습 내용과의 연결
- 필요할 때 Mermaid·ASCII 흐름도와 구조도
- 주의사항, 복습 우선순위, 다음 학습 확인 항목

사용자 메모는 가능하면 `notes/YYYY-MM-DD.md`에 저장합니다. 또한 사용자가 날짜별 문서 하단에 `#개인 기록` 제목으로 작성한 부분도 개인 메모로 취급합니다. 해당 블록은 사실·질문·어려웠던 점·복습 요청으로 구분해 본문에 `## 개인 기록 정리` 섹션으로 요약하고, 요약이 끝나면 원래의 `#개인 기록` 블록은 문서에서 삭제합니다. 개인 기록의 의미는 보존하되 확인되지 않은 내용은 추측하지 않습니다.

평일 저녁 정리에서는 당일 문서와 함께 다음 평일 날짜의 빈 학습 문서 초안을 미리 만듭니다. 주말·공휴일에는 다음 평일을 계산해 미리 만들며, 이미 존재하는 문서는 덮어쓰지 않고 필요한 안내만 보완합니다.

복습 문제는 `review/`에 저장하고, 답변·피드백·개인 학습 진도는 공개 저장소에 저장하지 않습니다.
