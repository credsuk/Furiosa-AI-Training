# 일자별 학습 정리

이 디렉터리에는 매일 저녁 20:00(KST)에 생성되는 학습 정리 문서를 저장합니다.

## 파일 형식

```text
doc/YYYY-MM-DD.md
```

각 문서에는 다음 내용을 포함합니다.

- 해당 날짜의 commit 메시지와 변경 파일
- commit별 학습 주제
- 반드시 기억해야 할 핵심 내용
- 코드 이해를 돕는 배경 설명과 예시
- 필요할 때 Mermaid·ASCII 흐름도와 구조도
- 주의사항과 다음 확인 항목

복습 문제는 `review/`에 저장하고, 답변·피드백·개인 학습 진도는 공개 저장소에 저장하지 않습니다.
