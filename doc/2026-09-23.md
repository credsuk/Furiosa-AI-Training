## 이날의 주제: optimizer 고도화와 시계열·ReduceLR

다양한 데이터셋에 Adam learning rate를 적용하고 ReduceLROnPlateau를 확장했으며 RNN·GRU·LSTM의 입력 구조와 시계열 모델을 학습했습니다.

## 반드시 기억할 내용

RNN 계열 입력은 `(샘플, timestep, feature)`입니다. 시계열 평가에서는 미래 데이터가 과거 학습에 섞이지 않도록 시간 순서를 보존해야 합니다.

```text
시계열 X: (batch, timestep, feature)
과거 구간 → 학습 / 이후 구간 → 검증·테스트
```

## 학습 보강: optimizer·시계열·ReduceLR

### Python 문법 반복

`for`로 여러 데이터셋에 같은 모델 실험을 적용할 때 반복 변수와 결과 변수를 구분합니다. 콜백 리스트를 `callbacks=[reduce_lr]`로 전달하는 것도 객체를 묶어 함수에 넘기는 문법입니다.

### NumPy 핵심

window 분할은 슬라이싱의 반복입니다. `data[i:i+timestep]`은 시작 위치 i부터 timestep개를 가져오고, `data[i+timestep]`은 다음 값을 target으로 선택합니다. 경계를 넘지 않도록 반복 범위를 계산해야 합니다.

### pandas 핵심

시계열 DataFrame은 먼저 시간순 정렬 후 feature 열을 선택하고 NumPy로 변환합니다. `df.iloc[:, :-1]`은 마지막 열을 제외한 위치 기반 선택이고, `df.iloc[:, -1]`은 마지막 열 Series입니다.

### 반복해서 기억할 점

RNN 입력 순서는 `(samples, timesteps, features)`입니다. ReduceLR은 validation 지표가 정체될 때 learning rate를 낮추는 것이며, 데이터 순서를 섞는 문제와는 별개입니다.
