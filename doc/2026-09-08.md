## 이날의 주제: EarlyStopping과 이진 분류

EarlyStopping을 적용하고 Cancer·Santander 데이터로 sigmoid와 binary_crossentropy 기반 이진 분류를 시작했습니다.

## 반드시 기억할 내용

분류에서는 회귀의 mse 출력 구조를 그대로 쓰지 않습니다. 이진 분류는 보통 sigmoid 1개 출력과 binary_crossentropy를 사용합니다.

```text
Dense(..., relu) → Dense(1, sigmoid)
                 ↓
          binary_crossentropy
```

## 학습 보강: 이진 분류의 출력과 라벨

### Python 문법 반복

조건에 따라 동작을 바꾸는 콜백 설정에서는 keyword argument 이름을 정확히 써야 합니다. `restore_best_weights=True`에서 `True`는 문자열이 아니라 Python의 Boolean 값입니다.

### NumPy 핵심

분류 라벨을 배열로 다룰 때 `y.shape`, `np.unique(y)`로 라벨 종류를 확인합니다. sigmoid 출력 `(n, 1)`과 정답 `(n,)` 또는 `(n, 1)`의 형태가 코드와 손실 함수 기대에 맞는지 확인합니다.

### pandas 확인

Cancer·Santander 원본 데이터를 DataFrame으로 다루는 경우, target 열을 feature에서 제거했는지 `X.columns`로 확인합니다. 이 문서에서는 pandas API의 직접 사용보다 모델 분류 구조가 중심이므로 세부 함수는 실제 코드에 등장할 때 반복합니다.

### 반복해서 기억할 점

이진 분류는 보통 마지막 출력 1개와 sigmoid, binary crossentropy 조합입니다. `predict` 확률을 0/1로 바꾸는 기준과 loss 계산용 y 형식을 혼동하지 않습니다.
