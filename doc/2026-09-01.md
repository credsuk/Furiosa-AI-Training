## 이날의 주제: NumPy shape와 다중 입력·출력 MLP

배열의 차원·shape·전치와 여러 특성을 가진 MLP를 학습했습니다. x의 행은 샘플, 열은 feature로 해석하고 y의 열 수는 출력 노드 수와 연결됩니다.

## 반드시 기억할 내용

transpose 뒤에는 샘플 수와 feature 수가 의도대로인지 확인합니다. shape가 맞지 않으면 input_dim 또는 마지막 Dense 크기에서 오류가 발생합니다.

```text
x.shape = (샘플 수, feature 수)
y.shape = (샘플 수, 출력 수)
```

## 학습 보강: shape·전치·자료구조

### Python 문법 반복

`x.shape`처럼 점(`.`) 뒤에 이름을 붙이는 것은 객체의 속성 또는 메서드에 접근하는 문법입니다. `x.reshape(...)`는 배열 객체가 제공하는 메서드를 호출하는 형태입니다. 속성은 보통 괄호가 없고, 함수·메서드 호출은 괄호가 있습니다.

### NumPy 핵심

2차원 배열에서 `axis=0`은 행 방향으로 내려가 열별 계산을 하고, `axis=1`은 열 방향으로 가로 계산을 합니다. 전치 `.T`는 `(샘플, feature)`를 `(feature, 샘플)`로 바꾸므로 모델에 넣기 전에 의도한 shape인지 확인해야 합니다.

```python
x = np.array([[1, 10], [2, 20], [3, 30]])
print(x.shape)          # (3, 2)
print(x.mean(axis=0))   # feature별 평균
print(x.T.shape)        # (2, 3)
```

### pandas 연결

pandas DataFrame도 행과 열 구조를 사용하지만 NumPy 배열보다 열 이름과 자료형 정보를 함께 관리합니다. `df.to_numpy()`를 사용하면 값만 NumPy 배열로 바뀌므로 변환 뒤에는 `.shape`를 다시 확인합니다.

### 반복해서 기억할 점

`x.shape == (샘플 수, feature 수)`, `y.shape == (샘플 수, 출력 수)`라는 기준을 매번 먼저 적습니다. 마지막 Dense의 노드 수는 y의 출력 열 수와 맞아야 합니다.
