## 시계열 복습 연결

사용자가 특히 어려워한 부분은 입력과 정답을 `x, y`로 분리하고, RNN에서 데이터를 window로 자르는 과정입니다. 다음 패턴을 중심으로 반복합니다.

```python
def split_x(dataset, size):
    windows = []
    for i in range(len(dataset) - size + 1):
        windows.append(dataset[i:i + size])
    return np.array(windows)

bbb = split_x(a, size)
x = bbb[:, :-1]
y = bbb[:, -1:]
```

`bbb[:, :-1]`은 마지막 timestep을 제외한 입력이고, `bbb[:, -1:]`은 마지막 timestep을 2차원으로 유지한 정답입니다. 다중 feature에서 `y[:, 0, 1]`은 첫 timestep의 두 번째 feature를 선택하는 표현입니다. `-1`과 `-1:`의 차원 차이, `axis`, `reshape` 전후의 원소 수와 값 순서를 작은 배열로 계속 확인합니다.

DNN·RNN·CNN의 기본 입력은 각각 `(샘플, feature)`, `(샘플, timestep, feature)`, `(샘플, height, width, channel)`로 구분합니다. `return_sequences=True`는 성능을 자동으로 높이는 옵션이 아니라 다음 RNN 층에 전체 시퀀스가 필요할 때 사용합니다.

하루를 144개 timestep으로 정의하는 실제 데이터에서는 `-144`, `-288`, `+144`를 외우지 말고 예측 시점 이전의 데이터만 X에 포함되도록 시작·끝 인덱스를 직접 계산합니다. RNN→LSTM/GRU→Attention→Transformer→GPT·BERT·LLM·RAG의 계보는 학습 방향으로 참고하되, 각 기술이 단순히 일렬로 대체되는 관계라고 단정하지 않습니다.

### 다음 복습 우선순위

4. `return_sequences`에 따른 RNN 출력 차이
