### Python 문법 반복

Markdown을 생성하는 자동 작업도 파일 읽기·문자열 조합·파일 쓰기의 순서로 동작합니다. 기존 파일을 읽지 않고 덮어쓰면 사용자의 메모가 사라질 수 있으므로 먼저 존재 여부와 내용을 확인해야 합니다.

### NumPy·pandas 반복

이날은 문서·복습 체계가 중심이라 NumPy·pandas 코드 변경은 확인되지 않았습니다. 다만 이전 학습의 shape, indexing, DataFrame 열 선택을 복습 문제에 연결해 반복합니다.

### 반복해서 기억할 점
