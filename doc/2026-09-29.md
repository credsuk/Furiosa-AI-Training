## 개인 기록 정리

### 가장 중요한 복습 요청: 시계열 window 분할

사용자는 입력과 정답을 `x, y`로 분리해야 한다는 점, RNN에서는 데이터를 어떤 길이로 자를지 결정하는 것이 핵심이라는 점을 기록했습니다. 다음 함수는 길이 `size`인 window를 만들고, 이후 마지막 부분을 입력과 정답으로 나누는 기본 패턴입니다.

```python
def split_x(dataset, size):
    windows = []
    for i in range(len(dataset) - size + 1):
        windows.append(dataset[i:i + size])
    return np.array(windows)

bbb = split_x(a, size)
x = bbb[:, :-1]
y = bbb[:, -1:]
```

`bbb[:, :-1]`은 마지막 timestep을 제외한 입력이고, `bbb[:, -1:]`은 마지막 timestep을 2차원으로 유지한 정답입니다. 다중 feature에서 특정 feature만 target으로 쓸 때는 `y[:, 0, 1]`처럼 축을 명시합니다. 이 부분을 시험 대비 핵심 복습 항목으로 기록합니다.

### shape와 모델 연결

사용자는 DNN·RNN·CNN의 데이터 차이를 비교했습니다. 일반적인 기준은 다음과 같습니다.

- DNN: `(샘플, feature)`
- RNN: `(샘플, timestep, feature)`
- CNN 이미지: `(샘플, height, width, channel)`

각 layer의 출력 차원을 다음 layer가 받을 수 있어야 하며, RNN 출력 뒤에 Dense를 연결할 때는 마지막 timestep만 반환하는지(`return_sequences=False`) 또는 모든 timestep을 반환하는지(`True`)를 먼저 확인해야 합니다. `return_sequences=True`가 성능을 자동으로 높여 주는 것은 아니며, 다음 RNN 층이 전체 시퀀스를 필요로 할 때 사용합니다.

### 실제 시계열에 적용할 때의 생각

하루를 144개 timestep으로 정의한 경우, 예측 대상 시점과 과거 입력 범위를 먼저 시간축에 표시해야 합니다. target 열을 먼저 분리하고, 예측에 사용할 수 없는 미래 구간을 X에서 제외한 뒤, X와 y의 시작·끝 인덱스를 맞춰야 합니다. `-144`, `-288`, `+144` 같은 숫자를 외우기보다 “예측 시점 이전의 데이터만 입력에 포함한다”는 원칙으로 다시 계산합니다.

### 모델 계보 메모

사용자는 RNN에서 LSTM·GRU, Attention, Transformer, GPT·BERT·LLM·RAG로 이어지는 흐름을 기억하려고 합니다. 이 계보는 큰 학습 방향으로 유용하지만 각 기술이 완전히 일렬로 대체되는 관계라고 단정하지 않고, 다음 단계에서 attention과 transformer의 역할을 별도로 학습합니다.

시험 문제와 NumPy 다차원 인덱싱이 어렵고, `reshape`할 때 값의 순서와 원소 수가 바뀌지 않아야 한다는 점을 반복 요청했습니다. 다음 복습에서는 작은 배열을 직접 만들고 매 단계마다 `shape`와 일부 값을 출력합니다.
