## 이날의 주제: 모델 저장·복원과 체크포인트

전체 모델 저장·불러오기, weights-only 저장·복원, ModelCheckpoint를 사용해 좋은 시점의 모델을 보존했습니다.

## 반드시 기억할 내용

model.save와 save_weights는 저장 범위와 복원 방법이 다릅니다. 체크포인트는 마지막 epoch가 아니라 검증 성능이 좋은 모델을 보존하는 데 유용합니다.

```text
학습 → validation 확인 → best checkpoint 저장 → 필요 시 복원
```

## 학습 보강: 저장 범위와 복원 계약

### Python 문법 반복

파일 경로를 문자열로 전달할 때 저장 함수와 불러오기 함수의 경로가 일치해야 합니다. `if`로 파일 존재 여부를 확인하는 경우 Boolean 표현식의 결과를 먼저 생각합니다.

### NumPy 핵심

`model.predict()` 결과나 저장된 weights는 NumPy 배열과 연결되지만, weights 파일은 단순한 `np.save` 배열과 복원 API가 다릅니다. 모델의 layer 구조와 weight shape가 맞는지 확인합니다.

### pandas 확인

이날의 중심은 Keras 저장·복원이며 pandas 직접 사용은 확인되지 않았습니다. 표 데이터 모델을 저장할 때도 데이터 전처리 scaler와 feature 열 순서를 별도로 보존해야 한다는 점을 반복합니다.

### 반복해서 기억할 점

`model.save()`는 구조·가중치·설정 등을 함께 저장하는 방식이고, `save_weights()`는 가중치 중심입니다. 체크포인트 파일명만 보고 best 모델이라고 단정하지 말고 monitor와 저장 조건을 확인합니다.
