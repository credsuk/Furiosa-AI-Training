## 이날의 주제: optimizer·learning rate와 RNN 시작

ReduceLROnPlateau, learning rate 조정과 다양한 회귀·분류·CNN 실험을 진행하고 SimpleRNN·RNN 입력 구조를 시작했습니다.

## 반드시 기억할 내용

learning rate가 너무 크면 불안정하고 너무 작으면 학습이 느립니다. ReduceLROnPlateau는 검증 개선이 멈출 때 학습률을 낮추는 방식입니다.

```text
validation 개선 정체 → learning rate 감소 → 더 세밀한 최적화
```

## 학습 보강: optimizer와 시계열 입력 시작

### Python 문법 반복

콜백과 optimizer를 함수 인자로 넘길 때 `ReduceLROnPlateau(monitor='val_loss', factor=0.5)`처럼 문자열·실수·Boolean의 자료형을 구분합니다.

### NumPy 핵심

시계열 배열을 `reshape(samples, timesteps, features)`로 바꿀 때 전체 원소 수가 유지되어야 합니다. `axis`를 잘못 이해하면 timestep과 feature가 뒤바뀌므로 변환 전후 shape를 출력합니다.

### pandas 확인

시계열 원본이 DataFrame이면 날짜 또는 시간 열을 정렬한 뒤 NumPy 배열로 변환해야 합니다. `sort_values()` 후 `to_numpy()` 순서가 모델 입력 순서가 됩니다. 해당 날짜 코드에서 pandas 직접 사용 여부는 파일별로 다시 확인합니다.

### 반복해서 기억할 점

learning rate는 한 번의 정답이 아니라 optimizer의 업데이트 크기입니다. validation 개선이 멈췄다고 학습을 즉시 끝내는 것과 learning rate를 낮춰 계속 시도하는 것은 다른 동작입니다.
