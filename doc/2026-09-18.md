## 이날의 주제: CNN 구조 확장과 이미지 증강 기반

CNN 모델을 보완하고 MaxPooling·GlobalAveragePooling·DNN/CNN 비교, ImageDataGenerator와 이미지 NPY 저장·복원 기반을 확장했습니다.

## 반드시 기억할 내용

Pooling은 공간 크기를 줄이고 주요 특징을 요약합니다. GlobalAveragePooling은 Flatten보다 파라미터를 줄이는 대안이 될 수 있습니다.

```text
Conv 특징맵 → Pooling/GAP로 공간 요약 → Dense 분류
```

## 학습 보강: Pooling·GAP와 배열 축

### Python 문법 반복

공통 모델을 함수로 만들면 인자에 따라 데이터셋이나 layer 구성을 바꿀 수 있습니다. 함수 인자 기본값과 반환값을 확인하며 읽습니다.

### NumPy 핵심

CNN feature map은 보통 `(batch, height, width, channels)`입니다. `GlobalAveragePooling2D`는 height·width 축을 평균내어 `(batch, channels)`로 줄입니다. Flatten은 공간 위치를 모두 펼쳐 더 큰 벡터가 될 수 있습니다.

### pandas 확인

이미지 증강 데이터는 generator 또는 NumPy 배열 중심이라 pandas 직접 사용은 확인되지 않았습니다. 표 형식 라벨을 사용할 때는 label 열의 고유값과 배열 순서를 확인합니다.

### 반복해서 기억할 점

Pooling은 공간 크기를 줄이고 GAP는 채널별 공간 평균을 냅니다. layer를 바꾼 뒤 각 출력 shape를 모델 summary와 함께 확인합니다.
