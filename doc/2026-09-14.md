## 이날의 주제: Dropout과 CNN 기초

Dropout 정규화, 함수화 실험, MNIST CNN과 Fashion/CIFAR CNN으로 이미지 입력을 다뤘습니다.

## 반드시 기억할 내용

Dropout은 학습 중 일부 연결을 끄지만 평가·추론 때는 일반적으로 비활성화됩니다. 이미지 입력은 높이·너비·채널 shape를 갖습니다.

```text
이미지 (H, W, C) → Conv2D → Pooling → Dense → 분류
```

## 학습 보강: 이미지 shape와 학습 모드

### Python 문법 반복

함수로 모델을 만들면 `def build_model(...):` 안의 변수는 함수 범위에 있습니다. 마지막에 `return model`을 해야 호출한 쪽에서 모델을 받을 수 있습니다.

### NumPy 핵심

이미지는 보통 NumPy 배열이며 단일 이미지 shape는 `(height, width, channel)`, batch를 포함하면 `(batch, height, width, channel)`입니다. `np.expand_dims(img, axis=0)`은 추론용 batch 축을 추가합니다.

### pandas 확인

CNN 이미지 학습 문서의 직접 데이터 구조는 NumPy 배열·generator이며 pandas 사용은 확인되지 않았습니다. CSV 라벨을 읽는 경우에도 이미지 배열과 라벨 행의 순서를 맞춰야 합니다.

### 반복해서 기억할 점

Dropout은 학습 중과 추론 중 동작이 다릅니다. Conv2D 입력의 channel 위치, batch 축, 픽셀 스케일을 항상 출력해 확인합니다.
